========================================================================
  AMBIENT COMPOSER AI  —  Install on Windows (for FL Studio)
========================================================================

You run ONE small file, ONE time. After that the plugin keeps itself
up to date automatically in the background — you never reinstall, and
you never need any programming tools.


------------------------------------------------------------------------
WHAT YOU NEED
------------------------------------------------------------------------
* Windows 10 or 11 (64-bit)
* An internet connection
* An account you can approve an admin prompt on (a normal home laptop
  account is fine)

That's it — no Visual Studio, no compilers, nothing to buy.


------------------------------------------------------------------------
STEP 1 — Run the setup file (one time)
------------------------------------------------------------------------
1. Save the file you were sent:   Setup-AmbientComposerAI.bat
2. Double-click it.
3. Windows may show a blue "Windows protected your PC" box (because the
   file isn't signed). Click "More info", then "Run anyway".
4. Click "Yes" when Windows asks for permission.
5. A window opens and does everything by itself:
      - downloads the plugin
      - installs it for FL Studio
      - switches on automatic background updates
   When it says "DONE!", press any key to close it.


------------------------------------------------------------------------
STEP 2 — Use it in FL Studio
------------------------------------------------------------------------
1. Open FL Studio.
2. Options  ->  Manage plugins  ->  click "Find installed plugins"
   (let it finish scanning).
3. Search "Ambient Composer AI" in the plugin list and add it to a channel.
4. Pick a MOOD, press "Generate Both", then press Play to hear it.
5. Drag the "Chords", "Melody", or "Combined" tile from the bottom of the
   plugin onto the FL playlist or piano roll. Assign your own instrument
   to the notes and play.


------------------------------------------------------------------------
UPDATES — nothing for you to do
------------------------------------------------------------------------
Whenever a fix or improvement is made, your laptop downloads and installs
it automatically in the background (within about an hour, and whenever you
log in). Just close and reopen FL Studio to pick up the newest version.

  * If FL Studio is open while an update arrives, that's fine — the update
    simply applies the next time, when FL isn't holding the plugin.


------------------------------------------------------------------------
IF SOMETHING GOES WRONG
------------------------------------------------------------------------
* The setup window shows a download error
      -> Check your internet connection and run Setup-AmbientComposerAI.bat
         again. (Nothing is harmed by running it more than once.)

* FL Studio doesn't show the plugin
      -> Run "Find installed plugins" again, and make sure VST3 scanning is
         on. The plugin is installed here:
         C:\Program Files\Common Files\VST3\Ambient Composer AI.vst3

* You want to see what the updater is doing
      -> Open this file in Notepad:
         C:\ProgramData\AmbientComposerAI\update.log

* To turn OFF automatic updates later
      -> Open "Task Scheduler", find "AmbientComposerAI-AutoUpdate", delete it.
         (The plugin stays installed; it just stops updating.)

* To UNINSTALL completely
      -> Delete these, then in Task Scheduler delete "AmbientComposerAI-AutoUpdate":
         C:\Program Files\Common Files\VST3\Ambient Composer AI.vst3
         C:\ProgramData\AmbientComposerAI
         C:\Users\<you>\AppData\Local\Programs\Ambient Composer AI
